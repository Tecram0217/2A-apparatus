# CODE:2A 3番版 — 消失装置からエンディングまで

このフォルダは、消失装置の対象入力から後日譚エンディングまでを独立させた版です。

## 動作

1. `index.html` で消失する人物の名字または氏名を漢字で入力します。
2. 消失演出と短い後日譚を進めます。
3. 選択した人物に対応するエンディングを表示します。
4. エンディング末尾の「消失装置へ戻る」で `index.html` に戻り、次の対象を入力できます。

## 対応する名前

- 小笠原／小笠原結衣 → FILE 01
- 相沢／相沢洸太 → FILE 02
- 神崎／神崎美月 → FILE 03
- 知念／知念誠也 → FILE 04

ブラウザで `index.html` を開くだけでも動作します。ローカルサーバーで確認する場合は `START.cmd` をダブルクリックすると、`http://127.0.0.1:4174/` で開きます。終了時は `STOP.cmd` を使用してください。
